# 📸 Photography Website Sidebar Menu

A simple photography website UI featuring a toggleable sidebar navigation menu, created using **HTML and CSS** while learning web development through **Apna College** tutorials.

This project helped me understand the fundamentals of web page structure, CSS styling, positioning, transitions, and interactive navigation menus.

## ✨ Features

- Toggleable sidebar navigation menu
- Open and close menu using icons
- Photography-themed background image
- Font Awesome icons
- Hover effects on menu items and social media icons
- Smooth CSS transitions
- Google Fonts integration using Poppins
- Simple and beginner-friendly UI

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, positioning, hover effects, and transitions
- **Font Awesome** – Icons
- **Google Fonts** – Poppins typography

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/yashdhonde88/photography.git
   ```

2. Open the project folder:

   ```bash
   cd Photography-Sidebar-Menu
   ```

3. Open `index.html` in your browser.

   You can also use the **Live Server** extension in Visual Studio Code.

## 📚 What I Learned

While building this project, I practiced:

- Creating HTML layouts using `div`, lists, links, and input elements
- Styling elements with CSS selectors
- Using `position: fixed` and `position: absolute`
- Applying CSS transitions and hover effects
- Creating a sidebar toggle using a checkbox and the CSS `:checked` selector
- Integrating Google Fonts and Font Awesome
- Organizing HTML and CSS into separate files
